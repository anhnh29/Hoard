## Project

Hoard is a Nuxt 4 application. It is currently a freshly scaffolded minimal starter (`app/app.vue` only renders `NuxtRouteAnnouncer` and the default `NuxtWelcome` component) — there is no custom application code yet.

## Commands

This project uses **pnpm** (declared via `packageManager` in package.json; a `pnpm-workspace.yaml` is present).

- `pnpm install` — install dependencies (runs `nuxt prepare` via postinstall)
- `pnpm dev` — start the dev server at http://localhost:3000
- `pnpm build` — build for production
- `pnpm generate` — generate a static site
- `pnpm preview` — preview the production build locally

There is no test runner, linter, or formatter configured yet. If you add one, record the commands here.

## Architecture

- Uses Nuxt 4's `app/` directory convention (srcDir defaults to `app/`) rather than the old root-level `pages/`/`components/` layout. New pages, components, layouts, composables, etc. should go under `app/` (e.g. `app/pages/`, `app/components/`) following standard Nuxt auto-import/auto-routing conventions.
- `nuxt.config.ts` is the single config entry point; currently only sets `compatibilityDate` and enables `devtools`.
- TypeScript config (`tsconfig.json`) is a thin wrapper that references the project-specific tsconfigs generated by Nuxt into `.nuxt/` (`tsconfig.app.json`, `tsconfig.server.json`, `tsconfig.shared.json`, `tsconfig.node.json`) — do not hand-edit `.nuxt/*`, it is regenerated by `nuxt prepare`/`nuxt dev`/`nuxt build`.
